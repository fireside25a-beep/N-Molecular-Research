# Technical provenance for the molecular graph-intervention study

The principal reader-facing document is **RESEARCH_MANUSCRIPT.pdf**, titled *Structural Sensitivity in a Native Spiking Neural Network Under Molecular Graph Interventions*.

The experiment consists of directed-contact-graph classification, chemical-bond ablation, computed RNA-pairing contacts, short-fragment atomic mechanics, and matched native spiking-network readouts.

The CSV fields `version` and some historical file paths preserve original development release identifiers solely to locate original files. They are **not** model names, independent biological experiments, peer-reviewed validation rounds, or scientific outcome definitions.

The source lineage is held in `data/PUBLICATION_FIGURE_PROVENANCE.csv`, the per-observation table, and `evidence_and_logs/COMPLETE_REPRODUCIBLE_EVIDENCE.zip`. Original source and binaries are available in `native_source_release/`. Older reports have been retained in `supplement/archival_manuscript_before_publication_refinement/` and `prior_portfolios/`.

The current manuscript is computational research evidence, not a claim of externally peer-reviewed acceptance or validated physical folding accuracy.
