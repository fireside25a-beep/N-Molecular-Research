Research summary

A compiled spiking neural network ran real counterfactual graph experiments on DNA/RNA-related categorical structures and chemical representations. The latest path calculates RNA secondary-structure contacts, attempts an H-type crossing motif, builds RDKit 3D conformers, computes real MMFF94 energies/gradients, and inserts derived contacts into the native neural network.

Correct scientific reading: Graph-label accuracy, neural firing disagreement and modeled folding energy are different outcomes. No experimentally validated full-RNA 3D structure accuracy or ligand binding prediction was established in these records.

Computational contract

Neural disagreement

D = Σ popcount(A[t] XOR B[t]) / (48 × 22), t = 0…47. The denominator is 1,056 binary target events per paired trial; each reported score is recomputed from original firing masks.

Classifier accuracy and statistical tests

Accuracy = correct graph labels / evaluated labels. Paired null-label permutations use p=(1 + #null≥observed)/(4097), and Holm correction for a declared comparison family.

Thermodynamics, forces and geometry

The RNA model includes selected Turner-type parameters and explicitly simplified remaining terms; it does not reproduce a complete RNAfold partition function. MMFF94 coordinate gradient checks use a symmetric finite-difference derivative of the force-field energy. V11 RNA mechanics apply only to four-nucleotide fragments.

Test evidence

The evidence ZIP contains the source audit, original full logs, data JSONL, hashes and an independent verifier. Archived 81-test logs are historical—not a claim that this portfolio renderer independently recompiled the whole runtime.
