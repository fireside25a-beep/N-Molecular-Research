# Folder structure and reading sequence

Root `START_HERE.md` and `index.html` are the public entry points.

```text
Molecular_Graph_Research_Publication_20261023/
├── 01_Research_Article/             Main 16-page paper, unchanged PDF + LaTeX
├── 02_Publication_Figures/         14 original data-derived figures
├── 03_Study_Guide/                Explanatory PDF and text; formulas
├── 04_Data_And_Results/           Original CSVs, workbook, data dictionary
├── 05_Technical_Supplement/       Evidence scope and technical validation
├── 06_Experimental_Evidence/      Exact original run logs and source evidence
├── 07_Reproduce_And_Verify/       New release verifier + original scripts
├── 08_Executable_Source_Archive/  Original source-built release and binaries
├── 09_Legacy_Edition/             Original prior editions, TeX, old charts and receipts
├── 10_Provenance_And_Integrity/   Source-to-current path map and SHA-256 ledger
└── 11_Editorial_Submission/       Journal instructions, unsigned draft declarations
```

Every original archival file occurs at one canonical new path. No original evidence files were deleted. Reader-facing file names are organized by scientific role. Historical version identifiers remain solely inside original data and preserved archives.
